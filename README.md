# Project Management App 

A modern project management application inspired by Trello.

User can create boards, lists, cards, assign users, add comments, 
move cards, track activity and manage project workflow.


## features

- Authentication
- Boards
- Lists
- Cards
- Drag and Drop
- Labels
- Due Dates
- Comments
- Activity Timeline
- Member Assignment
- Dark Mode


## Tech Stack

Frontend:
- React
- Vite
- Tailwindcss
